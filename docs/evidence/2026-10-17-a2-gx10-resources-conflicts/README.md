## T11：既有目标与真实竞争

使用此前已保存独立摘要的两份不同内容 CIFS 快照，NAS 仅作只读输入；全部新目标位于本轮
专属 ext4 目录。没有重新发布、重放旧恢复或改变 NAS 挂载、服务、容量和权限。

- 空目录、非空目录、断链、带旧 WAL 的目录、普通文件五种既有目标：全部 TARGET_EXISTS / not_applicable，退出 4；原成员、字节及记录的元数据不变。
- 同一快照的两个恢复进程竞争同一新目标，以及不同快照的两个进程竞争同一新目标：两组均先证明双方已到达最终独占 mkdir 边界，再同时释放；每组恰有一个 published / exit 0，另一个 TARGET_EXISTS / exit 4。
- 两组胜出目标都只有单链接 `ledger.sqlite`，字节与胜出输入一致；全部 SQL 行、实际 Blob 及独立 CLI check_restore 均通过。两份 NAS 原输入不变，没有暂存 DB 残留。

竞争只在测试进程的最终 mkdir 前加入同步等待；实际 mkdir、文件系统分类、复制、链接、同步
和 SQLite 都保持真实执行。所列两组时序通过，不推广为穷尽所有并发调度。
