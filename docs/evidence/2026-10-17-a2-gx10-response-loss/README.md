## 证据边界

create 响应完全丢失时，调用前尚无 manifest 摘要。本次按[接口规定](../../a2/INTERFACE_PROFILE.md)
从确认归属的原目录计算候选摘要，再验证当前自洽性；不把事后候选摘要冒充事前独立摘要，
不据此证明精确历史 T0 或历史调用成功。restore 的核对使用在它启动前已保存的引用。
`check_restore` 也不补做同步、不证明历史发布过程或硬件持久性。

未覆盖 NAS 发布丢响应、NAS-only 恢复、挂载消失、断网、发布过程中止、设备断电以及完整 T01–T15。

公开摘要不包含机器路径、端点、凭据或原始数据库。
